# Libft

## Description
Libft is a custom C library made as part of the 42 School curriculum.  
The goal of this project is to recreate common libc functions and build useful additional functions that will be used in future projects.

This library includes:
- String functions
- Memory functions
- Character checks
- Linked list functions
- Utility functions

## Instructions

### Compile the library
```bash
make
````

### Clean object files

```bash
make clean
```

### Remove object files and library

```bash
make fclean
```

### Recompile everything

```bash
make re
```

## Files

* `libft.h` → Header file
* `ft_*.c` → Source files
* `Makefile` → Build system
* `libft.a` → Compiled static library
